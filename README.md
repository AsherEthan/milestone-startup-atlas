# 里程碑 · 创业作战地图

基于《里程碑》一堂五步法的交互式 Three.js 网页。使用原生 JavaScript、Three.js 和 Vite，不依赖远程字体、贴图或 CDN。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev -- --port 5173
```

浏览器打开终端显示的本地地址，通常是 http://127.0.0.1:5173 。不要直接双击 `index.html`，ES modules 需要通过 HTTP 服务加载。

## 功能

- 程序生成的等高线地形、五个阶段旗标、连接路径与行进光点。
- 拖动旋转、滚轮或按钮缩放、重置视角。
- 点击地形（Three.js Raycaster）、地图标签或阶段导航，查看阶段详情。
- 行动指南、过关信号、常见陷阱、交付物及来源边界。
- 阶段地址锚点，如 `/#business`。
- 完整文字地图；WebGL 不可用时自动降级；高对比度模式显示文字等价内容。
- FALSE 验证工具箱、实验边界、灰度／组合／里程碑测试速览。
- 完整工具库：49 个入口、9 类主题，支持搜索、分类、里程碑筛选和工具地址直达。
- 地图阶段与对应工作表互通，不需要离开地图逻辑寻找工具。
- 可填写的访谈、调研、需求评估、产品内核、实验、经营与复盘工作表。
- 市场规模四法、TAM/SAM/SOM、单元账本、三点预测、动态预测等交互计算。
- 各工具自动本地保存；支持版本说明、快照、与当前草稿比较、恢复前自动备份。
- Markdown 单工具／全部记录导出，JSON 完整备份与校验后导入。
- 作战画布：状态、假设、证据和下一次验证；保留原有的五步画布存储，不被新工具记录覆盖。
- 导出包含个人记录、五步行动与过关信号的 Markdown 文件。
- 手机端自适应布局、键盘操作与减少动态效果支持。

画布数据不会上传。不同浏览器、不同 origin（包括端口）之间不共享记录；清理网站数据会删除记录，请及时导出。无法使用本地存储时，页面会明确提示，当前会话仍可填写并导出。

## 界面与交互

- 统一的纸张／地形视觉语言：字号、间距、圆角、输入框和按钮均使用语义化设计变量。
- 首页增加清晰的三步使用路线与画布入口；阶段说明、更多工作表和验证方法速览按需展开，避免所有说明争抢首屏。
- 工具箱增加四个常用问题入口；手机目录默认收起，选中工具后回到当前工作表。
- 手机记录可在“卡片”和“表格”之间切换；两种呈现使用同一份输入 DOM，切换与调整窗口不会复制或清空数据。
- 顶部可选择浅色、深色或跟随系统；Three.js 地形、地面、路线、旗帜和灯光独立适配，不使用反色滤镜。
- 主题使用独立键 `milestone-theme-v1`，不修改画布或工具记录。保存偏好失败时，本次会话仍可切换。
- 工具地址 `/#tool/工具ID` 与画布地址 `/#canvas` 支持刷新后留在当前工作区。
- 设计原则、响应式与无障碍验收见 [界面设计规范](docs/UI设计规范.md)。

## 使用 Skill：把方法带到自己的 AI 工具

顶部“使用 Skill”进入独立指南页（`/#skills`），不打开分析弹窗。主要入口是“复制安装并开始指令”：粘贴到支持安装 Skill 的 AI 工具，让它安装并开始使用；不必先下载文件。网页只复制文字，不执行本机安装，也不表示已安装。ZIP 保留为备用方式，原阅读说明仍在页脚“关于这张地图”。

| Skill | 适用场景 | 主要产出 |
| --- | --- | --- |
| `skills/product-clarity/SKILL.md` | 从自己的产品想法开始，逐轮澄清用户、需求、产品内核和商业模式 | 产品作战卡、关键假设与本轮实验卡 |
| `skills/business-teardown/SKILL.md` | 拆解成熟企业、品牌或具体业务线，明确地区、时期和证据口径 | 两大假设、五步拆解、九格全貌、单元经济、证据台账与可迁移经验 |

### 推荐：在 AI 工具对话框里安装并开始

1. 选择 Skill，点击“复制安装并开始指令”。
2. 发到支持联网、文件写入和 Skill 的 AI 工具中（以 Claude Code 为例），按工具提示批准必要操作。
3. 工具从本仓库读取对应 `skills/技能名/SKILL.md`，安装到当前项目并启用；已有同名文件会先询问，不改变全局设置，不运行其他仓库脚本。
4. 安装完成后直接开始产品梳理或商业拆解。如需刷新技能列表或重开会话，按工具提示完成，再输入 `/product-clarity` 或 `/business-teardown`。

安装指令完整可预览；复制成功不等于安装成功。普通网页聊天通常不能替电脑安装技能，不支持安装时请用下方“复制完整指引”的方式。

### 普通 AI 聊天：不用安装

1. 选择一份 Skill，点击“复制完整指引”。
2. 在你常用的 AI 助手中新建对话，粘贴并发送完整指引。
3. 再介绍你的产品，或指定要拆解的企业、业务线与时期，按追问补充资料。

这是将 Skill 当作对话指引使用，不等于在该平台原生安装技能；效果取决于所用模型和工具。

### 备用：手动下载安装

无需克隆整个网站仓库，直接在 [Skill 使用指南](https://asherethan.github.io/milestone-startup-atlas/#skills) 下载 `product-clarity.zip` 或 `business-teardown.zip`。每个压缩包只含对应的 `技能名/SKILL.md`，解压即有正确的技能文件夹。

以 Claude Code 为例，把解压后含 `SKILL.md` 的文件夹复制到当前项目的 `.claude/skills/` 下；不要再套一层同名目录。可只安装需要的一份：

```text
.claude/skills/
├── product-clarity/
│   └── SKILL.md
└── business-teardown/
    └── SKILL.md
```

个人全局安装可放在 `~/.claude/skills/`。安装后输入 `/product-clarity` 或 `/business-teardown`，再描述需求。其他工具请遵循各自安装规范；下载文件本身不会自动安装或运行。详见 [Claude Code 官方说明](https://code.claude.com/docs/en/skills)。

- 网页不接收产品描述、不读取或附带画布及工具库记录、不提供在线推理，也不要求 API Key。
- 复制的指引和 ZIP 中的 `SKILL.md` 始终与原始 Skill 文件一致，不拼接任何个人资料；ZIP 在浏览器本地生成。请在外部 AI 工具中自行提供必要内容，并检查其数据政策。
- 指南页提供 [GitHub Star 入口](https://github.com/AsherEthan/milestone-startup-atlas)，由使用者登录 GitHub 后主动操作；下载和使用无需先 Star，网站不调用 Star API。

- `/#tool/version-history`：所有工具的历史版本。

### 填写、版本与备份

- 填写会立即尝试保存到 `milestone-toolbox-v1`；旧的五步画布仍使用 `milestone-atlas-v1`。
- 工具支持重复记录行，最多 100 行；三点预测固定保留三个情景。
- 每个文本字段最多 5,000 字，版本说明最多 200 字；每个工具最多 50 个版本。达到上限不自动删除旧版本；可以先导出 JSON，再确认移除不需要的版本。
- “保存版本”留存当前所有字段和表格，包括 259 的三个粒度。“比较／查看”展示与当前草稿的差异及历史内容。
- 恢复版本前需要确认，并自动保存恢复前草稿。如果无法先保留草稿（例如版本已满），不执行恢复。
- JSON 备份包含所有工具、完整版本历史和原有五步画布；导入校验通过后还需确认覆盖。格式错误不会替换当前记录，导入上限为 10 MB。
- Markdown 用于阅读和分享，单工具和全部记录都可导出；它不是可恢复完整历史的备份格式。旧五步画布另有原来的 Markdown 导出按钮。
- 存储拒绝／容量不足时明确提示，不宣称已落盘；当前会话仍可编辑和导出。读取到损坏的旧工具记录时不会悄悄覆盖原始内容。

### 测算口径

- 空白不是 0；数字需有限，输入绝对值与结果的上限为 10¹⁵，百分比为 0～100%。超限请统一换算为万元等口径，缩小数值量级。
- 市场四法并列展示，不自动取平均；TAM、SAM、SOM 必须使用同一地区、年份、币种与收入口径。收入不等于 GMV 或利润。
- 单元账本区分变动成本、固定成本和一次性投入。周期利润不等于现金流，静态回本期只使用用户另填的同周期净现金流，不用利润替代。
- 三种情景独立填写，不自动拼成“合理值”。动态模型单独扣除未分摊总部成本，不重复分摊。
- 频次×刚性只给经营提示，不对机会强行排名；用户价值差额只是同一自定义量表下的概念比较。
- 比例指标遇到零分母显示“未定义”，分子超过同口径基数会提示检查。不给出通用成功分数、行业及格线或投资结论。

## 构建与预览

```bash
npm run build
npm run preview -- --port 4173
```

`dist/` 是静态部署产物。Three.js 按核心、渲染器与场景分包加载。Vite 使用相对资源路径 `base: './'`，支持站点根目录和 GitHub Pages 仓库子路径；部署时只需托管整个 `dist/`。页面导航使用 hash，不需要服务端路由重写。

## 内容边界

两份原始材料正文结束于第七章“商业模式”。工具库的“材料 01”指《里程碑01.pdf》的 Markdown 提取，“材料 02”指《里程碑02.pdf》的 Markdown 提取；行号对应原始 `full.md`，不是 PDF 页码。

需求、产品内核、单元模型和验证方法依据原文整理；增长、壁垒依据总论、案例和目录建立框架，具体执行建议为实操补充。增长周期、增长飞轮、护城河工具明确标注“正文缺失”，通用工作表不冒充原书专章。调研武器库、FALSE 的 18 子策略小抄存在 OCR 损坏，只保留可靠部分和待核记录。KANO、马斯洛、福格、用户体验地图等明确标为参考笔记，而非声称原文有完整教学。

交付物与过关信号是实操归纳，不是书中规定的统一验收标准。地形高度、距离不编码难度、时间或用户的真实完成进度。地图不是保证成功的公式，也不代替行业许可、安全、税务及法律判断。
