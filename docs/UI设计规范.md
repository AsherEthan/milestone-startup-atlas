# 里程碑 · 界面设计规范

## 设计方向

保留“创业野外手册”的自然绿色、纸张和地形语言，但从说明页调整为可以长期工作的界面。视觉重点依次是：当前问题、下一步操作、支撑证据；不以装饰或虚构的成功进度抢占注意力。

## 信息架构

- **探索地图**：理解五个里程碑 → 选择当前阶段 → 阅读核心问题 → 打开对应工具。
- **验证工具箱**：搜索／分类／阶段筛选 → 工具目录 → 当前工作表 → 测算与证据 → 版本留存。
- **作战画布**：横向对齐五个阶段的状态与笔记，保留直接探索和导出入口。
- **AI 分析**：顶部入口 → 选择产品梳理／成熟商业拆解 → 可选补充资料 → 完整预览 → 复制或下载 Skill。它是离线指引分享，不伪装成在线推理；旧阅读说明保留在页脚。
- 方法论速览保留完整内容，但默认折叠，避免与工作台争夺首屏。
- 资料边界始终通过文字标识；“正文缺失”不以普通成功颜色掩盖。

## 基础系统

`src/design-system.css` 是颜色、间距、字号、圆角与主题的共同来源。页面组件使用语义变量，不通过滤镜反转深色界面。

- 间距使用 4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 正文主要为 14～16px，辅助信息至少 12px。地图的紧凑标签结合等价阶段导航使用。
- 标题、正文、来源和操作按钮有明确层级，不把所有内容做成同等强调的卡片。
- 主按钮用于当前页面的主要动作；导出、帮助、筛选重置使用次级样式。
- 普通文字目标对比度不低于 4.5:1；大字号文字和重要图形至少 3:1。
- 交互控件以 44px 为触控目标；焦点不只依靠颜色，使用清晰描边。

## 响应式

- **手机**：单列工作区；目录可以收起，选工具后回到编辑；宽表格只在自身容器内滚动。
- **平板**：保留较大的文字和操作目标，地图和阶段详情堆叠。
- **桌面**：地图与阶段详情双列；工具目录与工作表双列；侧栏在有足够视口高度时保持可达。
- 宽度变化不清空字段、不丢弃表格行，也不改变选中的里程碑。
- 放大到 200% 时使用窄屏布局，不把操作藏在整页横向滚动区域中。

## 主题与动效

- 浅色、深色、跟随系统三个选项始终可达；主题偏好使用独立存储键，不修改业务记录。
- Three.js 的地面、地形、路线、旗帜和照明使用对应主题，不对画布应用 CSS 反色。
- 支持减少动态效果；高对比度模式使用完整文字地图。
- 不使用远程字体、图片或额外的大型 UI 框架。

## 验收

1. 三个主视图在桌面与手机上均无整页横向溢出。
2. 现有 49 个工具、计算、版本、备份和旧画布记录不回退。
3. 深浅主题能即时切换、重新加载后保持，系统主题能响应系统变化。
4. 键盘能完成导航、筛选、填写、折叠、弹窗关闭和主题切换。
5. 检查地图标签碰撞、表格输入、对话框、错误与空状态。
6. 通过浏览器交互、截图检查、回归测试和生产构建。

## 检查范围

- `tests/ui-design.spec.js` 覆盖 320 / 390 / 768 / 1440px 视口、三个工作区、原生弹窗、目录跨断点行为和地图标签碰撞。
- 主题测试检查系统偏好响应、手动选择优先级、刷新持久化、存储失败提示，以及两个业务存储在切换主题时不被改写。
- 手机卡片／表格共用同一份输入元素；测试同时检查值和 DOM 身份，避免只保留视觉外观而丢失编辑状态。
- 自动对比度检查覆盖共享正文、辅助文字、主操作、焦点与输入边框的关键颜色组合。输入边框使用独立的 `--input-border`，不把装饰分隔线当作表单边界。
- 浏览器截图检查覆盖深浅地图、工作表、作战画布、版本比较及手机资料弹窗；另检查 720px 窄屏重排。
- `tests/ai-skill.spec.js` 检查双 Skill 预览／下载、独立草稿与主动分享范围、剪贴板失败反馈、关闭后的焦点归还，以及 320 / 390 / 1440px 双主题布局；操作反馈位于弹窗内的 live region，不依赖背景中的提示条。
- 这些检查不是完整的 WCAG 合规认证；屏幕阅读器、不同系统字体和真实触屏设备仍适合在发布前补充人工验收。
